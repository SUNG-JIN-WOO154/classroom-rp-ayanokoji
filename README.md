# CLASSROOM RP — AYANOKOJI

Un RPG narratif immersif et sombre inspiré par Classroom of the Elite. Incarnez Kiyotaka Ayanokoji et naviguez dans un lycée d'élite où chaque choix a des conséquences réelles et durables.

## Fonctionnalités

- Système de choix avec conséquences réelles
- Personnages dynamiques avec confiance, méfiance et historique
- Variables cachées qui influencent les scènes futures
- Progression temporelle sur 7 jours et 6 créneaux horaires
- Inventaire complet
- Sauvegardes rapides et chargement
- Journal détaillé
- Interface premium sombre et responsive
- Événements aléatoires

## Installation

```bash
git clone https://github.com/SUNG-JIN-WOO154/classroom-rp-ayanokoji.git
cd classroom-rp-ayanokoji
npm install
npm run dev
```

Le jeu est alors disponible sur http://localhost:3000.

## Comment jouer

1. Choisissez une action dans les scénarios.
2. Observez l'impact sur la réputation, l'argent et les relations.
3. Vérifiez le journal pour les conséquences cachées.
4. Sauvegardez régulièrement pour garder votre progression.
